Extreme Heatwave Early Warning & Human Thermal Stress Index

Smart India Hackathon 2026
Ministry of Earth Sciences · NCMRWF
Software · Disaster Management

Input
NCMRWF / IMD forecast fields
Output
Ward-level stress index + alert
Stage
Data pipeline and index model

A warning built on temperature alone gets this wrong. 44°C in dry air and 38°C in humid air put very different loads on a body that still has to work outside, and the humid one is usually the more dangerous of the two.

So the output isn't a temperature threshold. I take forecast fields for heat, humidity, wind and radiation, compute a human thermal stress index from them, and turn that into a ward-level warning with enough lead time to act on. Machine learning does the bias correction on the forecast; the index itself stays physical, because a number that triggers a public alert has to be explainable.

The assistant lives inside WhatsApp instead of a dashboard nobody opens. It answers whoever tags it in a group, and reminds managers about their own plans by tagging them back, in the thread where the work is already being discussed.

The demo has been running across live groups for a while. The version I'm scaling to is harder: hundreds of groups, a different manager in each, and the same manager across several of them. Most of the real engineering is session handling, rate limits and surviving reconnects.
